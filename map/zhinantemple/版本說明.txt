指南宮 Q 版互動導覽｜最新版路線整合 2026-11-04

資料來源：使用者最新上傳之 zhinan-map(4).json。

1. 小人行走路線：原始 JSON route.points（241 點）及 route.curveHandles（33 組）完整更新。
2. 纜車線與支柱：原始 JSON cableway.points（9 點）及 towerIndices（[1,3,5,7]）完整更新。
3. 公車路線：原始 JSON bus.points（7 點）更新。
4. 景點資料：9 個景點、參觀順序、照片 URL、來源網址、停留秒數，與使用者上傳 JSON 相同。
5. 速度：行走速度 10、交通工具速度 5；採用上傳 JSON 內的設定。
6. HTML 原有之路線編輯、照片編輯、面板預設收合、音效、走路動畫預載與重新整理後續走功能保留。
7. 新 JSON 也直接內嵌至 HTML，因此單獨雙擊 index.html 時可使用相同預設值。
8. 透過本機伺服器開啟時，會優先讀取同一資料夾的 zhinan-map.json，因此請將兩檔保持同步。

注意：若先前在同一瀏覽器分頁有保存過導覽進度，網頁可能依續走功能恢復對應路段；路線已變更時，路線簽章會自動使舊進度失效。
