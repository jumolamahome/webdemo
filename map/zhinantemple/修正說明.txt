指南宮 Q 版地圖－小人中途閃爍與意外重置修正版

修正項目：
1. 導覽位置每隔約 0.35 秒保存至同一分頁的 sessionStorage。
2. 意外重新整理時，若 JSON 路線未變且記錄仍在 6 小時內，接續之前的路段、進度與行進方向。
3. 景點停留倒數也會記錄，重新整理後照片顯示完成才繼續倒數。
4. 走路動畫 8 張影格預先建立並解碼，只切換影格可見度，避免每 115 毫秒替換 Base64 src 引起閃白。
5. 使用「重設」按鈕、編輯模式或匯入不同 JSON 時，正常清除先前位置記錄。
6. 小人、纜車及公車路線、曲線控制點、景點照片、音效、控制面板及 JSON 維護功能皆保留。

注意：進度只保存在同一瀏覽器分頁；若手動按「重設」，會確實從起點重新開始。
建議讓 index.html 與 zhinan-map.json 保持同一資料夾，或直接雙擊 HTML 使用內建預設路線。
