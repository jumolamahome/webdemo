指南宮 Q 版互動導覽地圖｜底圖瑕疵修補重打包版

本版以「景點文字 JSON 化與節點焦點版」為基礎，只替換 HTML 內嵌的無景點文字底圖，並更新同資料夾中的底圖 PNG。
保留原有 HTML、JSON、景點編輯、站序標示、節點焦點、步行路線、纜車與支柱、公車路線、動畫與音效相關功能。

檔案：
- index.html：主程式，已內嵌修補後地圖及走路動畫素材
- zhinan-map.json：景點名稱與座標、照片 URL、步行路線、纜車線/支柱、公車路線等資料
- 指南宮Q版地圖_無景點文字底圖.png：修補後的底圖原始檔

使用方式：解壓縮後，建議讓上述檔案維持在同一資料夾，再以瀏覽器開啟 index.html。
若使用本機伺服器，可讀取同資料夾的 zhinan-map.json；若直接開啟 HTML，則使用 HTML 內建的預設 JSON。
