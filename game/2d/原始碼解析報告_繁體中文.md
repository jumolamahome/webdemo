# 《Beyond Castle Wolfenstein》2D 版原始碼初步解析

分析對象：使用者上傳的 `bcw_src.zip`  
檢查日期：2026-10-14  
內容：`BCW.ASM`（1,118,443 bytes、21,197 行）、`CONSTANT.INC`（2,145 bytes、99 行）  
版本資訊：`BCW.ASM` 開頭註明「Beyond Castle Wolfenstein version 0.2 - july 17th 2004」。

## 一、這份程式碼是什麼

- 這是 2004 年 Jeff Leyda 對原始 IBM PC 版本所做的**反組譯、註解與調整後的重建程式碼**，並非直接出土的 1984 年 Apple II 原始碼。
- 開頭記載 Silas Warner 為原始遊戲概念與程式設計者；若干程式符號名稱依然無法辨識，以 `v####`、`sub_##`、`loc_##` 命名，因而不宜宣稱已完全理解每個細節。
- 使用 8086 組合語言及當時 BIOS／DOS 中斷服務，包含文字／繪圖、音效、磁碟讀寫、記憶體管理等模組。
- 啟動流程在 `main`（132 行起）、`startGame`（154 行）、`mainLoop`（279 行起）。程式碼可供演算法研究，但無法把 `.ASM` 直接改副檔名成 `.js` 來執行。

## 三、四項最值得忠於原作的核心設計

1. **單畫面房間、跨房持續狀態**：進入房間時載入室內物件資訊，離開時寫回資料，讓玩家回到舊房間仍保留遊玩結果。
2. **警衛盤查不是純射擊 AI**：偵測玩家、要求通行證、賄賂與警報是遊戲的特色，應以狀態機重新設計。
3. **射擊包含隨機性**：`fireGun` 第 696–709 行先扣子彈，確認命中對象後再利用隨機值決定結果；網頁版可模擬此精神，但機率不是每個版本都能直接視為相同。
4. **滲透—取物—放炸彈—逃離**：`setBomb`、`detonateBomb`、物品與房間狀態共同構成任務流程，而不是單純清光敵人。

## 四、這次製作的 HTML5 研究原型

檔名：`BCW_1984_2D_HTML5_原型.html`。

**目前已實作（現代重寫）**：

- Canvas 像素化繪圖、黑底／磚牆／綠門、人物八方向移動。
- 3×3 九間房間，移動時切換房間，保留已拾取物品／警衛狀態。
- 警衛巡邏、盤查、出示通行證、賄賂、警報、射擊與玩家受傷。
- 手槍扣彈／裝填、約 70% 概念性隨機命中、匕首近身攻擊。
- 撿拾通行證、金錢、工具、急救包、炸彈；部分門需要較高通行等級或工具組。
- 炸彈設置、倒數撤離、成功／失敗畫面。
- 暫停、背包、網頁瀏覽器 localStorage 存檔、手機方向鍵與動作按鈕。

**暫時未還原原作**：

- 原始 1984／1985 年版本的逐像素圖資、精確房間拓樸、原始音訊和字型。
- 所有原始物品、鎖具機率與互動細節、完整章節與隨機地圖機制。
- 完全相符的敵軍行為流程、通行證編碼和 DOS 原版存檔格式。

上述 HTML5 作品是「**玩法研究原型**」，不是經驗證的 1:1 準確移植，也**沒有使用**原版圖片與音訊。

## 五、著作權與散布注意

`BCW.ASM` 開頭有一段較特殊的說明：一方面記載由 Silas Warner 的遺孀「donated ... to the public domain」，另一方面又要求程式繼續開放、免費，並反對將其用於營利作品。這些文字在法律效果上不宜簡化成「所有用途都自由、所有平台素材都無版權」。

若要從學術研究進展到公開的原版重製或商業發行，應釐清不同程式版本、商標、美術、音效，以及重建程式新增部分的適用權利；本研究原型因此採用獨立撰寫的 JavaScript 和原創簡化圖像。

## 六、建議下一階段

1. 按照原始組合語言，深入還原 `loadRoomData` 的二進位房間格式、各物件型別與跨房連結。
2. 針對 `bribeGuard`、`shootingGuard`、`checkAlarm` 逐一建立狀態圖和測試案例。
3. 分離 HTML、CSS、JavaScript、地圖 JSON，建立可編輯的關卡系統。
4. 製作玩家可切換的「舊版 1984 風格／現代 UI 風格」。
5. 在確認素材權利後，才考慮進一步還原原版圖片、音效及字型。
