鋼鐵堡壘 II — 網頁 FPS 遊戲 UI 四階段作品
====================================

本專案為原創教學用同類型網頁遊戲，參考復古軍事第一人稱射擊作品的介面風格，
非《德軍總部 / Wolfenstein》官方遊戲或重製版本，未使用原作程式碼。

四個主要檔案
------------
01_鋼鐵堡壘II_UI線框圖.png
  對照首頁、第一人稱戰鬥 HUD、暫停介面以及手機觸控 UI 的配置。

02_鋼鐵堡壘II_HTML_CSS_UI.html
  獨立靜態 UI 展示頁，可用左側導覽在首頁、遊戲 HUD、暫停、設定、
  任務成功、任務失敗六種畫面之間切換。

03_鋼鐵堡壘II_可玩FPS.html
  真正可玩的單檔 HTML5 Canvas 2.5D Raycasting FPS 遊戲。
  功能包含：迷宮、碰撞偵測、敵人移動與攻擊、擊中判定、武器動畫、
  裝填、彈藥與補給、生命／護甲／小地圖、過關與下一關、合成音效、手機觸控。

04_鋼鐵堡壘II_首頁到遊戲互動流程.html
  單一 HTML 裡串連「首頁 → 任務簡報 → 真正可玩的 FPS 戰鬥畫面」。
  遊戲完整內嵌在檔案裡，無需額外安裝或呼叫第三方 CDN。

電腦操作
--------
W / A / S / D    前進、左移、後退、右移
← / →          旋轉視角
滑鼠移動          點擊遊戲畫面後可轉向（游標鎖定）
滑鼠左鍵 / 空白鍵  射擊
R                 重新裝填
P / ESC           暫停／返回
M                 切換小地圖

手機操作：畫面中虛擬按鍵可控制轉向、前後移動、射擊、裝填與暫停。

遊戲目標
--------
清除所有守衛，再前往地圖右下角的黃色 EXIT 出口。
紅點表示敵人，白點表示自己，淡藍色標記是補給道具。
走到出口會顯示完成畫面，可以選擇下一關。

執行方式
--------
解壓縮後，直接用最新版 Chrome 或 Edge 開啟 HTML 檔即可。
無需安裝 Node.js、Python 或外掛，也不需要連網。
建議以電腦桌面瀏覽器遊玩第 03 版；手機請將畫面轉成橫向，以便操作。
